# sezim-kyzuzatuu

Цифровое приглашение на кыз узатуу. Статический сайт для Vercel.

## Деплой на Vercel

1. Откройте [vercel.com/new](https://vercel.com/new) и войдите через GitHub.
2. Import репозитория `isan228/sezim-kyzuzatuu`.
3. Framework Preset оставьте **Other**. Build Command и Output Directory не заполняйте.
4. Нажмите **Deploy**.

Админка: `https://<проект>.vercel.app/admin`
